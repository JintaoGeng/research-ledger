GitHub 同步设置

首次使用请：
1. 在 GitHub 新建一个仓库（可设为 Private），例如 research-ledger；
2. 到 github.com/settings/tokens 生成一个 Token，勾选 repo 权限；
3. 填写上方四项并保存。数据将保存在仓库的 data.json 中，任何设备配置一次即可同步。
启用 GitHub Pages（Settings → Pages → 选 main 分支）后，即可通过网页在各设备访问。
